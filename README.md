# Viveci

App de treino personalizado. React + TypeScript + Vite + Tailwind v4.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # testes das regras de negócio
npm run build
```

Leia o `CLAUDE.md` antes de mexer: ele tem o design system, as regras de negócio
e a ordem de construção.

O banco fica no Supabase (projeto `Viveci APP`). Os scripts estão em `sql/`.
